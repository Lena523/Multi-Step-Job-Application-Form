# Multi‑Step Job Application Form

## A fully responsive, wizard‑style job application form built with **React + TypeScript + Vite**, featuring advanced validation, Tailwind styling, and a smooth user experience.

## ✨ Features

- 🧙 **3‑Step Wizard Interface**
    - Step 1: Personal Information
    - Step 2: Experience & Education
    - Step 3: Review & Submit
    - Final: Success Page

- ✔️ **Validation with React Hook Form + Yup**
    - Real‑time field validation
    - Error messaging per field
    - Step‑blocking until valid

- 💾 **Persistent Data**
    - Form state preserved when navigating between steps
    - LocalStorage persistence across refreshes

- 🎨 **Tailwind CSS v4 Styling**
    - Modern, responsive UI
    - Mobile‑friendly layouts

- 🧪 **Testing Setup**
    - Vitest
    - @testing-library/react
    - Jest‑DOM matchers
    - jsdom environment

- 🧹 **Code Quality**
    - ESLint (TypeScript‑aware)
    - Prettier
    - Husky pre‑commit & pre‑push hooks
    - lint‑staged to fix staged files automatically
